# ✅ To-Do List – TaskFlow

A simple and responsive task management application built with **HTML, CSS, and JavaScript** to organize and manage daily tasks efficiently.

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 🔍 Search tasks
- 🏷️ Filter tasks by category and status
- 📊 Task statistics
- 💾 Data persistence using Local Storage
- 🌙 Light/Dark theme
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
